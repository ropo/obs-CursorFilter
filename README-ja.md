# OBS Cursor Filter

[English](README.md) | 日本語

Windows のマウスカーソルをゲームキャプチャに重ねて表示する OBS Studio のエフェクトフィルタです。Windows のポインターサイズ設定に合わせ、設定済みの `.cur` ファイルからカスタムカーソルの細部を保って表示できます。

Windows 版 OBS Studio 33 向けです。

## インストール

OBS を終了し、`obs-cursor-filter` フォルダーを `C:\ProgramData\obs-studio\plugins` に配置してから OBS を起動します。フォルダーには `obs-cursor-filter.dll`、`data\manifest.json`、`data\locale` が必要です。

ポータブル版 OBS の場合は、ポータブル版のフォルダー内にある `plugins` に配置してください。

## 使い方

1. ゲームキャプチャの「カーソルをキャプチャする」をオフにします。
2. ソースの「フィルタ」を開き、エフェクトフィルタに「カーソル描画」を追加します。
3. ゲームキャプチャが「特定のウィンドウをキャプチャ」の場合、その対象を自動で使用します。それ以外の場合は「ゲームキャプチャの対象ウィンドウを使用」をオフにし、ウィンドウを手動で選択します。
4. OBS のプレビューでカーソルの位置とサイズを確認します。必要に応じて「サイズの微調整」を変更してください。`1.0` が Windows のサイズ設定に合わせた値です。

自動選択では、設定されたタイトル・クラス・実行ファイルがすべて一致するウィンドウを探します。ゲームのタイトルが変化する場合や OBS の一致方法が異なる場合は、手動で指定してください。対象ウィンドウがアクティブなときだけ表示する設定もあります。

このフィルタは、キャプチャ映像がウィンドウのクライアント領域全体に対応することを前提としています。全画面モードや画面の拡大率、ゲームの解像度によっては位置がずれる場合があります。ゲーム映像内に描かれるカーソルは消せません。HDR や DPI の異なる複数モニターは未検証です。
